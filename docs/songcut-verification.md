## 关键行为

- 同录音的增益、整体偏移与内部剪辑可形成高拟合候选；不同人声/相同伴奏、纯音和过短音频不自动确认重复。
- 不覆盖源音频；成品解码复测；修改范围、制作参数或来源版本会改变派生身份。B 站 CID 变化使用新的下载缓存。
- Filetrans 超时提交不自动重发；已有 task_id 恢复时只轮询 GET；结果对象下载不携带 API key。
- 并发共享预算并串行化相同收费请求；STOP 在上传后仍会复查；崩溃留下的不确定提交阻止后续收费调用。
- 成本按提交时配置的单价结算为估计值；缓存读取或修改单价不会改写已结算的历史估计值。
- 字词分句拒绝重叠、越界和截断 JSON；遗漏词保留为 uncertain；扩写及 LRC 注入回退；冲突短窗保留双方证据。
- 中日文参考歌词进行发音比对，参考时间不导入现场歌词；输出保持 draft，已改动且标记人工审阅的歌词不会被重建覆盖。
- 单曲失败保留同批其它结果；CLI stdout 只有结果 JSON；真实 MCP worker 完成后可仅凭磁盘记录读取结果。

## 验证边界

音频制作使用了真实 FFmpeg 与合成信号。云端 ASR/Omni、LRCLIB、S3 和临时上传使用离线传输替身，
没有调用真实付费模型、上传用户音频、运行真实平台下载或验证新的歌曲识别准确率。
本地 Whisper 的新编排路径由替身验证，未在这次工作中运行真实模型权重。
默认模型与地区的账户可用性、当前单价、真实演唱质量和逐曲听审仍需在实际运营任务中核实。
