# Songcut Implementation Plan

**Goal:** 将经过 vup 批次验证的完整音频制作与云端歌词处理迁入可独立运行的 BliSolver，并发布双语“制作歌切”说明。

**Architecture:** 新增可选 songcut 管线和独立制品 schema，复用 provider acquisition 与 MCP 作业基础。原始媒体、播放成品、ASR 原始词、歌词候选和审阅证据分别保存，使用输入/参数/工具身份恢复。

**Tech Stack:** Python 3.11+、Pydantic、FFmpeg、NumPy/SciPy、requests、可选 boto3、argparse、现有 MCP SDK。

## Global Constraints

- 普通 ingest/Atlas 1.1 接口保持兼容；歌词永不自动 reviewed。
- 不读取 vup 运行凭据，不复制原始媒体/歌词到 Git，不启动付费或直播网络测试。
- 输入音频不可变，JSON 原子保存，收费 POST 结果不明不自动重发。
- 下载串行、API 最多 7 并发、CPU 独立限制，单曲失败保留其它结果。
- stdout 只输出结果 JSON，运行诊断走 stderr。
