# 制作歌切

用户已确认迁入完整音频处理管线及外部 API，README 明确展示“制作歌切”。本规范落实已确认的范围：通用媒体制作在 BliSolver，成员、专辑编排与站点发布留给调用方。

## 接口和范围

新增独立 `songcut` CLI 和对应异步 MCP 工具，不改变普通 ingest 的 Atlas 1.1 契约。输入是 BV/URL、本地媒体，或包含明确曲目和起止秒数的 JSON 清单。输出包括不可变播放音频、现场 LRC/TXT、原始转录、词索引、来源/处理哈希、去重关系、演唱候选判断、质检和运行收据。已有源文件始终保留；不自动改用户歌库或把模型结果标成已试听。

输入清单支持曲名、语种、演唱者说明、参考歌词文件、起止范围、参考音频库，以及 none/whisper/dashscope 后端。未知曲名或语种不凭成员猜测。未提供起止范围时处理完整媒体，不宣称自动把整场录播识别成完整歌单。

## 方案选择

1. 独立 Python songcut 模块，复用来源获取与 CLI/MCP 基础设施（采用）：避免 vup 日期目录、成员常量和 TypeScript 运行时进入工具包。
2. 原样调用 vup 脚本：不可独立安装，保留历史批次耦合，不采用。
3. 将制作逻辑直接塞入普通 ingest：将歌词候选与权威转录混在一起，不采用。

## 执行阶段

来源核验/获取 → 解码与切段 → 音频指纹召回及密集/分段相干度核验 → 播放音频制作 → 整段 ASR → 有界独立短窗补识别 → 演唱候选审查 → 参考歌词及发音比对 → 按词索引整理歌词与独立口播复核 → 成品质检及制品清单。

参考录音去重只判断同一录音，不识别歌手，不合并同曲不同演唱。重复项保存对齐及代表来源，不借用另一时间轴的歌词。演唱归属模型输出只能形成候选或 needs-review；聊天、背景原唱、跟唱保持不同结果。一个曲目失败不取消其它曲目。

## 音频与版本

FFmpeg 解码为 PCM 后按有效范围切段，80 Hz 高通、15 kHz 低通；默认保留动态，以测量的响度和真峰值计算受峰值约束的恒定增益。目标 -16 LUFS、真峰值 -1.5 dBTP；无法同时满足时允许略轻并记录原因。可显式选择两遍 dynamic loudnorm，记录第二遍实际 normalization_type。导出 48 kHz 双声道 AAC 192k，再解码测量成品、检查样本时长与峰值。原文件不覆盖。

缓存身份包含输入 SHA-256、实际范围、制作配置、算法版本及运行工具版本；转录另包含模型、参数和最终播放音频 SHA。引用歌词文件也参与身份。每次验证缓存制品哈希；配置变更创建新版本。运行状态原子保存，有进程锁和持久化阶段结果；重复执行不重复已成功的收费请求。

## 外部 API

迁入现有 DashScope Filetrans、Flash 短窗和 Omni 音频/文字能力。提供可配置的 API 地址、模型和费用估算单价，凭据从环境变量加载，不写入配置/收据/日志。主转写使用异步 task_id，GET 轮询可恢复；付费 POST 提交结果不明时保留 uncertainty，不自动重发。原始响应脱敏留存，结果 URL 及时下载。

文件上传支持已有 S3 兼容对象存储（boto3/环境凭据）及用户显式选择的 DashScope 临时上传。临时存储仅用于开发测试；生产由自有存储承担。调用方设置批次估算费用上限；在请求前持久化预留，未知用量不释放预留，超过预留停止后续收费调用。预算是配置单价估算，不代表供应商账单硬限额。

默认不调用云端；dashscope 后端需要 API key 和正数预算。API 并发最多 7，下载串行，CPU 制作有独立上限。STOP 文件阻止新收费请求，已提交异步任务仍可收集结果。

整段主转写保留输入覆盖和词时间。短窗由空结果、长空窗、语种/指定疑点触发，重叠窗有明确 core 范围，保留冲突。分句模型返回已有词索引，不生成时间戳；重叠、越界、遗漏和过量扩写受到本地检查。遗漏词保留为 uncertain；参考文本不凭空补未唱段落。所有新歌词为 draft。

## 交付、兼容和验证

实现文件放在 `blisolver/songcut/`，只由新的入口加载 NumPy/SciPy/requests/boto3 可选依赖。Python 下限 3.11。CLI stdout 为单个 JSON，进度走 stderr；路径从结果读取。MCP 使用持久化作业和不透明 job_id，工具返回真实结果路径；普通视频工具保持兼容。

README.md 与 README_zh.md 增加功能、安装 extra、离线制作与云端实例、清单、制品与候选边界。同步 skill 路由和参考，新增 API 配置示例与文档；不复制私密配置或真实媒体到仓库。

验证覆盖真实合成音频的切段、响度与动态、同录音变体/不同录音反例、损坏缓存、词覆盖、收费请求不确定状态、预算/停止/恢复、单条失败隔离、CLI/MCP JSON，以及原有离线测试。外部网络转写使用传输替身验证契约，不自动调用付费模型。交付明确标明哪些是离线契约验证，哪些有真实音频执行证据。
